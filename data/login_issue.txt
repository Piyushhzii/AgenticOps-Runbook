Runbook Name: Login Issue Troubleshooting
Issue Category: Authentication

Description:
This runbook is used when a user reports that they are unable to log into the system.

Troubleshooting Steps:

1. Ask the user for the exact error message displayed on the screen and classify it:
      - If it says the password is wrong/incorrect or invalid credentials → go to step 4 (password reset).
      - If it mentions the account is locked, disabled or too many attempts → go to step 2.
      - If it is about an MFA / one-time code → escalate to L2 support.
      - For any other or unclear error → go to step 2.
2. Check in the admin system whether the user account is locked.
3. If the account is locked:
      - Unlock the account.
      - Then go to step 5 (ask the user to try logging in again).
4. If the account is not locked, or the error was a wrong password:
      - Ask the user to reset their password using the "Forgot Password" option and confirm when done.
5. Ask the user to attempt login again and confirm whether it works.
      - If login works → the issue is resolved.
6. If the issue still persists after these steps:
      - Escalate the issue to Level 2 (L2) support with all collected details.
